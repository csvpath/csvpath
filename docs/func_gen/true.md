
## true()

yes() always evaluates to True. It is similar to no() and none().

| Purpose                | Value                              |
|:-----------------------|:-----------------------------------|
| Main focus             | true() produces a calculated value |
| Aliases                | yes, true                          |
| Has internal variables | False                              |
